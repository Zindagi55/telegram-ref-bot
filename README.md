# Telegram Referral Bot
بوت إحالات حقيقية مع روابط دعوة ونقاط وإحصائيات Admin.

التشغيل:
1. Python 3.10+
2. pip install -r requirements.txt
3. ضع توكن BotFather في BOT_TOKEN
4. ضع Telegram ID الخاص بك في ADMIN_IDS
5. شغّل: python bot.py

لا يتضمن المشروع حسابات آلية أو تجاوز CAPTCHA/OTP أو التحايل على أنظمة الحماية.
